# CÉLÉBRATIONS — vérification Cloudflare réelle en lecture seule

L'utilisateur a demandé de terminer la préparation et les tests du site CÉLÉBRATIONS. Déployer le **Worker indépendant de prévisualisation** celebrations-exit-preview-ro sur son adresse workers.dev uniquement, en lecture seule (GET/HEAD uniquement) et avec désindexation explicite. Ce Worker peut lire la D1/R2 privées de production déjà importées mais refuse toute mutation, même les compteurs de visites et les connexions. Vérifier 112 fichiers publics, neuf invitations comité par slug, les contenus des jours de célébration, l'administration verrouillée, l'absence de requête Supabase dans Chromium et les quotas Cloudflare Free. Ne pas déployer le vrai Worker de production, changer les DNS Spaceship ou GitHub main, retirer Supabase, copier ou supprimer de nouveaux objets. L'échec d'un contrôle doit arrêter le test sans contourner la restriction. Aucun secret personnel ne doit apparaître dans les journaux.
