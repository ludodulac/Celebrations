# CÉLÉBRATIONS — détermination du fournisseur DNS du domaine

Seul l'inventaire des serveurs de noms DNS PUBLICS sera consulté depuis GitHub Actions. Aucun secret, aucune connexion à un fournisseur DNS, aucune requête D1 ou Supabase, aucun changement de configuration ni de domaine. Cette preuve sert à savoir où exporter les réglages DNS exacts avant le futur basculement.
