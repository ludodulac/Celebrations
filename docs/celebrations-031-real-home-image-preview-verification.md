# CÉLÉBRATIONS — vérification du rétablissement de l'image d'accueil

Déployer uniquement la version mise à jour du Worker indépendant `celebrations-exit-preview-ro` (GET/HEAD-only, sans secret admin, sans DNS). La photo d'accueil doit désormais charger depuis le chemin original privé `media/1791723108110/file-1791723109615-1000040461.jpg`, déjà inclus dans la copie R2 de production et son ACL. Les tests doivent certifier le fichier JPEG de 167220 octets (HEAD 200) et une image réellement décodée par Chromium sur mobile (`naturalWidth>0`), ainsi que les 113 autres contrôles médias publics, neuf liens comité, sept journées, aucune requête Supabase. Ne pas modifier les données D1/R2, GitHub main, les DNS ou les secrets de connexion. **Attention : le Worker de prévisualisation est sans connexion admin ; ses POST sont bloqués par conception, donc le mot de passe administrateur ne peut pas y être testé.** La configuration et le test d'un Worker d'administration sécurisé sont une étape distincte.
